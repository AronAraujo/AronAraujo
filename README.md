## 🚀 Featured Projects

### 🛍️ Esportiva Shop — Fullstack E-commerce

A digital football shirt catalog developed for a real small business, with an administrative dashboard and product management.

**Technologies:** Next.js, TypeScript, PostgreSQL, Prisma, Cloudinary.

- Product catalog, search, filters, and pagination.
- Admin authentication and product management.
- Image uploads and external service integration.
- Responsive interface for desktop and mobile.

🔗 [Live Application](https://esportiva-shop.vercel.app/) | [Repository](https://github.com/AronAraujo/esportiva-shop)

### 🤖 AI Financial Agent — Multi-Agent Automation

An automated customer service workflow built with n8n and Google Gemini, using Telegram as the communication interface.

**Technologies:** n8n, Google Gemini API, Telegram API, Google Sheets, Google Calendar.

- Receives and processes text and audio messages.
- Uses AI to identify user intent and route requests.
- Integrates specialized agents for support, scheduling, and financial inquiries.
- Connects external services through APIs.

🔗 [Repository](https://github.com/AronAraujo/n8n-ai-financial-agent)

### ⚽ Aruan — Football Tryout Management API

A REST API developed with Java and Spring Boot to manage football clubs and coaches in sports tryout processes.

**Technologies:** Java, Spring Boot, Spring Data JPA, H2, Maven.

- REST endpoints for registration, listing, searching, and deletion.
- Relational entity modeling and data persistence.
- Backend development using Spring Boot.

🔗 [Repository](https://github.com/AronAraujo/Peneiras-de-Futebol-JavaSpringBoot)

### 🚗 Jaron — Dealership Management System

A desktop application developed to manage dealership operations, including inventory and sales.

**Technologies:** Java, MySQL.

- Inventory and sales management.
- Relational database modeling.
- CRUD operations and SQL queries.

🔗 [Repository](https://github.com/AronAraujo/Concessionaria-Jaron_Java-SQL)
